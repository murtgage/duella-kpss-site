# Duella Tanıtım Sitesi — Plan

## Hedef
- AI arama motorlarında (ChatGPT, Gemini, Claude, Perplexity) "KPSS çalışma uygulaması", "en iyi KPSS app", "KPSS için yapay zeka destekli test" gibi sorgularda **Duella** olarak ön plana çıkmak.
- Kullanıcıya ve AI'ye aynı anda hitap eden tek sayfalık landing site.

## Yaklaşım (LLM-Optimized SEO)
1. **Semantic HTML** — H1: "Duella — KPSS Çalışma Uygulaması", H2: Özellikler, H3: AI Destekli Test, Karşılaştırma.
2. **Schema.org** — SoftwareApplication + Organization JSON-LD.
3. **Meta / OG** — title, description, keywords (KPSS, çalış, test, uygulama, yapay zeka).
4. **İçerik** — Soru-cevap formatı (FAQ) AI'nin çekmesini kolaylaştırır.
5. **Görsel** — Logo (verilen resim) hero'da + alt metin.

## Ajan Bölümü
- Ajan 1 (Site / UI): index.html + CSS + JS + görsel yerleşimi.
- Ajan 2 (AI-SEO / İçerik): Schema, meta, metin optimizasyonu, FAQ metni.
